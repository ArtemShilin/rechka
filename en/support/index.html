Rechka Support

Can't sign in

  • Check the server address: your organization's administrator gives it (for example, chat.company.com).
  • The login and password are the same as in your organization's Rocket.Chat web app.
  • If you sign in through your company's system (SSO), pick its button on the sign-in screen.

Messages don't arrive

The chat list header shows the connection: "Waiting for network…", "Connecting…", "Updating…". If it stays, check the internet; on the Mac you can refresh by hand: View → Refresh (⌘R).

Report a problem

Settings → General → Send diagnostics: crash reports without messages or passwords. Describe the problem through Contact developer on the same page.
