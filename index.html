Речка

Быстрый мессенджер для общения с коллегами. Подключается к серверу Rocket.Chat вашей организации: чаты, треды, файлы, голосовые и видеозвонки. Бесплатно, без рекламы и без сбора данных.

Скачать

  • Windows 10 и 11 — Microsoft Store (бесплатно; входить в учётную запись Microsoft не нужно)
  • iPhone, iPad и Mac — скоро в App Store

Установка из командной строки (Windows), например для администраторов:

winget install --id 9N2LPV7HCM4V --source msstore --accept-package-agreements --accept-source-agreements

Что нужно для работы

Учётная запись на сервере Rocket.Chat — её выдаёт ваша организация или администратор сервера. При первом запуске укажите адрес сервера, затем логин и пароль.
